# Payli

Payli is a glassmorphism-inspired mobile payment portal that gives professional service
teams a polished experience for moving money and collecting client payments.

## Getting Started

```bash
npm install
npm run dev
```

The application will start on [http://localhost:3000](http://localhost:3000). Use the
“Receive payment” or “Send funds” quick actions to launch the transfer sheet and submit a
test request.

## Features

- Mobile-first glass effect interface with a warm, professional color palette that can
  switch between brown and creme themes
- Tabbed navigation for Home, Reports, and Settings views inside the app shell
- Send & receive dashboard module with contextual stats and quick transfer triggers
- Client transfer sheet with validation for core contact details, movement type, and
  accessible focus management
- Express server with mocked transfer endpoint that returns a reference for send/receive
  flows
- Responsive layout across desktop and mobile viewports
