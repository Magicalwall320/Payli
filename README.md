# Payli

Payli is a glassmorphism-inspired mobile payment portal that gives professional service
teams a polished experience for collecting client payments.

## Getting Started

```bash
npm install
npm run dev
```

The application will start on [http://localhost:3000](http://localhost:3000). Use the
“Create charge” quick action to launch the payment sheet and submit a test payment.

## Features

- Mobile-first glass effect interface with a warm, professional color palette
- Tabbed navigation for Home, Cards, Reports, and Settings views inside the app shell
- Client payment sheet with validation for key card details and accessible focus management
- Express server with mocked payment endpoint that returns a receipt reference
- Responsive layout across desktop and mobile viewports
